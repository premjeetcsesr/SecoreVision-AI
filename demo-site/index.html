How to Load the Extension in Chrome / Firefox / Edge

Test the Privacy Vision Agent on any live website across the internet.

1

Open Extensions Manager

Navigate to chrome://extensions/ or edge://extensions/ in your browser.

2

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the extensions page.

3

Load Unpacked Extension

Click Load unpacked and select the mini-projctct-kit/extension/ folder.

4

Start FastAPI Backend

Run python -m uvicorn backend.main:app --port 8000 and click the extension icon to automate!
